# 1社限定トライアル運用 手順

リハーサル（10 PASS）後、実クライアント1社で**2週間・送信なし**の限定パイロットを行う。

## 前提（Notion確定シートで先に決める）
1. 対象1社・対象業務（見積・請求依頼のみ）
2. 承認者（担当マネージャー／PDF化承認者／送付承認者＝当面未設定）
3. 初期安全設定（`outbound_enabled=false` 維持・受信口座は1つだけ）
4. 成功条件（2週間 受付漏れゼロ／全案件で担当・期限・実績時間記録／想定対実績差・差戻し理由を週次レビュー）

## 投入手順
1. 実データseedを作る（`db/seed.your.sql`・**コミットしない**。`.gitignore`済み）。実トークンはダミーから差し替え。
2. 受信口座を**1つだけ**有効化し、送信は口座・全体ともOFFのまま：
   - `inbound_enabled=1`（対象口座のみ）、他は `inbound_enabled=0`
   - `outbound_enabled=0`（全口座）、`ALLOW_OUTBOUND_SEND=false`
3. Webhookを実チャネルに接続（Chatwork）。`CHATWORK_INGEST_ENABLED=true`。
4. 2週間運用し、週次でメトリクス（`/api/metrics`）と実績時間を確認。

## 2週間後
- レビュー（受付漏れ・担当/期限/実績の記録率・想定対実績差・差戻し理由）。
- 実送信の有効化は、このレビュー後に**別途判断**（`outbound_enabled`と`ALLOW_OUTBOUND_SEND`を揃える）。
- 品質評価・速度評価は、実測が貯まってからロジックを定義する。

## 禁止・注意
- 金額はAIが確定しない（依頼のまま）。送付・発注・契約判断は寺嵜さんの確認後。
- 個人情報・機微情報はリポジトリ/テストデータに保存しない。
